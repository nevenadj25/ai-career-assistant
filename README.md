# AI Career Assistant

AI Career Assistant is a full-stack web application developed as my final thesis project. The main goal of this application is to help people improve their career prospects, prepare for job applications, and develop their professional skills using Artificial Intelligence.

The application integrates **Google Gemini AI** to generate personalized career-related content and assist users throughout the job application process.

## Features

### 1. AI CV Generator

- Create professional CVs by entering personal information.
- Add education, work experience, skills, languages, projects, and certificates.
- Choose between different CV templates.
- Generate CV content with AI assistance.
- Receive AI-powered CV analysis and suggestions for improvement.

### 2. AI Cover Letter Generator

- Generate personalized cover letters using AI.
- Provide information about the desired job position and company.
- Include the job description to generate more relevant and tailored cover letters.

### 3. AI Interview Preparation

- Generate technical interview questions based on user-selected technologies.
- Choose the number of questions and difficulty level.
- Practice answering technical interview questions.
- Receive AI-powered evaluation and feedback on submitted answers.

### 4. User Authentication

- User registration and login.
- JWT-based authentication.
- Protected API endpoints.
